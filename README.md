# AI Prompt Lab

Локальная лаборатория для контролируемого тестирования и публикации промптов AI‑рекрутера и AI‑продажника.

```bash
cd /media/vladimir/WORK/VIBE_CODING/LEARNING_UII/ai-prompt-lab
npm run dev
```

Откройте `http://127.0.0.1:5184`.

## В текущей версии

- каталог двух агентов и стартовые профили;
- защищённая логика статусов `draft → tested → published` в API;
- тестовые наборы с видимым разделением 80/20;
- реестр версий, метрики, независимый holdout и журнал типичных ошибок;
- схема Prisma, задающая целевую PostgreSQL-модель для следующего этапа подключения БД.

Демонстрационные данные живут в памяти сервера. Для боевого запуска необходимо подключить Prisma/PostgreSQL, а публикационный адаптер — к API существующего AI‑администратора.
