# AI Prompt Lab

Публичная демонстрационная лаборатория для контролируемого тестирования версий промптов AI‑рекрутера и AI‑продажника.

```bash
cd /media/vladimir/WORK/VIBE_CODING/LEARNING_UII/ai-prompt-lab
npm run dev
```

Откройте `http://127.0.0.1:5184`.

## Демо-режим

На Vercel Vite-клиент отдаётся как статический сайт, а `/api/*` обслуживает
serverless API. Демо-режим предназначен для учебной проверки: состояние и
введённый OpenAI API key хранятся только в памяти запущенного экземпляра
сервера. Они не коммитятся в Git, но могут исчезнуть после перезапуска или
масштабирования Vercel. Для постоянного многопользовательского продукта нужна
отдельная база данных и полноценная авторизация — это выходит за рамки ДЗ.

Не добавляйте OpenAI API key и локальные файлы состояния в репозиторий:
`.gitignore` уже исключает `.env*`, `.secrets*` и файлы локального состояния.

## Проверка перед сдачей

```bash
npm ci
npm test
npm run build
```

На публичном URL проверьте: старт демо-сессии, создание и сравнение версий
промптов, ввод собственного ключа в «Админке» и обновление списка моделей.
Для GitHub Actions сохраните ссылки на намеренно красный и последующий зелёный
запуск; затем выполните обычный merge Pull Request в `main` — Vercel развернёт
production автоматически.

## В текущей версии

- каталог двух агентов и стартовые профили;
- защищённая логика статусов `draft → tested → published` в API;
- тестовые наборы с видимым разделением 80/20;
- реестр версий, метрики, независимый holdout и журнал типичных ошибок;
- сравнение двух версий промпта построчно: добавления, удаления и счётчики изменений;
- GitHub Actions: `npm ci`, unit-тесты и production-сборка на Node.js 20.

Демонстрационный контур не является постоянной многопользовательской базой.
